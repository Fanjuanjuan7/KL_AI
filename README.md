# KL账号批量注册工具 (KL_AI)

## 简介
本工具是一款专业的自动化注册管理系统，专为Kling平台设计。它集成了智能IP资源管理、邮箱资源池管理以及比特浏览器(BitBrowser)自动化调度功能。系统支持多线程并发操作，具备完善的任务队列管理和异常处理机制，能够显著提升账号注册效率。

## 核心功能

### 1. 注册任务管理 (自动化核心)
- **智能调度**: 支持多线程并发注册，根据剩余任务量动态调整并发数。
- **任务控制**:
  - **目标设定**: 可设置本次运行的目标注册数量（达到即停）。
  - **实时监控**: 界面实时显示「已成功 / 本次目标 / 最大可注册」数据。
  - **一键启停**: 提供醒目的开始/停止按钮，支持中途安全停止任务。
- **自动化参数**:
  - 可自定义元素超时时间、检测间隔、最大重试轮数。
  - 支持启用/禁用XPath自动化流程。

### 2. IP资源池管理 (智能轮询)
- **循环复用 (Round-Robin)**: 
  - 实现IP地址的均匀轮询使用，确保资源利用率最大化。
  - 自动记录IP使用位置，程序重启后继续轮询，避免资源浪费或过度使用。
- **灵活导入**:
  - **文件导入**: 支持TXT/CSV文件批量导入。
  - **粘贴导入**: 支持直接粘贴文本（格式：`IP:端口:用户:密码` 或 `IP`）。
  - **默认填充**: 对于仅提供IP的数据，自动应用预设的端口、账号、密码及协议。
- **状态追踪**: 实时显示每个IP的已使用次数和剩余可用次数。
- **协议支持**: 全面支持 socks5, http, https 代理协议。

### 3. 邮箱资源池管理
- **内置管理**: 摒弃传统CSV文件依赖，直接在界面内管理邮箱资源。
- **状态同步**: 自动标记已注册成功的邮箱，防止重复使用。
- **便捷操作**: 支持批量导入、粘贴导入、导出未使用邮箱等功能。
- **验证码集成**: 记录并显示验证码接收链接，便于人工辅助或调试。

### 4. 系统配置与持久化
- **自动保存**: 所有界面参数（路径、配置、阈值）修改后自动保存。
- **路径自适应**: 智能处理文件路径，支持相对路径，确保在不同电脑或目录下直接运行。
- **容错机制**: 配置文件丢失或路径错误时，自动尝试恢复默认设置或搜索同级目录。

## 文件结构说明

| 文件名 | 用途 | 依赖关系 |
| :--- | :--- | :--- |
| **gui_ctk.py** | **主程序入口**。基于CustomTkinter构建的图形界面，负责用户交互、参数配置和任务调度。 | 依赖 `ip_manager.py`, `email_manager.py`, `register_kling_bitbrowser.py` |
| **ip_manager.py** | **IP管理器**。负责IP数据的加载、存储、轮询分配及状态更新。 | 被 `gui_ctk.py` 和注册逻辑调用 |
| **email_manager.py** | **邮箱管理器**。负责邮箱数据的去重、状态跟踪及增删改查。 | 被 `gui_ctk.py` 和注册逻辑调用 |
| **register_kling_bitbrowser.py** | **注册核心逻辑**。实现具体的浏览器自动化操作、流程控制及异常处理。 | 依赖 `BitBrowser` API |
| **kling_xpaths.json** | **页面元素定位配置**。存储注册流程中各步骤的XPath定位符，支持热更新。 | 被注册核心逻辑读取 |
| **ip_pool.json** | **IP数据存储**。保存IP列表及其使用状态（自动生成/更新）。 | 由 `ip_manager.py` 管理 |
| **email_pool.json** | **邮箱数据存储**。保存邮箱列表及其状态（自动生成/更新）。 | 由 `email_manager.py` 管理 |
| **gui_config.json** | **用户配置存储**。保存界面上的各项参数设置（自动生成）。 | 由 `gui_ctk.py` 管理 |

## 环境配置与安装

### 1. 系统要求
本工具基于Python开发，支持跨平台运行：
- **Windows**: Windows 10/11 (推荐)
- **macOS**: macOS 10.15+ (Intel/Apple Silicon)
- **Linux**: Ubuntu 20.04+, CentOS 7+ (需安装桌面环境支持GUI)

### 2. 软件依赖
- **Python**: 3.8 或更高版本
- **比特浏览器 (BitBrowser)**: 必须安装并运行，开启RPA/API接口（默认端口 54345）。

### 3. 安装步骤 (源码运行)
1. **克隆/下载项目**:
   ```bash
   git clone https://github.com/YourRepo/KL_AI.git
   cd KL_AI
   ```

2. **创建虚拟环境 (推荐)**:
   ```bash
   # macOS/Linux
   python3 -m venv .venv
   source .venv/bin/activate

   # Windows
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. **安装依赖库**:
   ```bash
   pip install -r requirements.txt
   ```
   *(注: 如果没有requirements.txt，请安装: `customtkinter`, `requests`, `pandas` 等常用库)*

### 4. 打包为可执行文件 (可选)
如果需要在无Python环境的机器上运行，可使用 `pyinstaller` 打包：
- **Windows**: 运行 `run_build_windows.bat`
- **macOS**: 运行 `run_build_mac.sh`
- **手动打包**: `pyinstaller --noconsole --onefile --add-data "kling_xpaths.json:." gui_ctk.py`

## 网页自动化注册

- 功能概述
  - 通过比特浏览器打开目标网站，按照 XPath 路径自动执行注册流程，包含语言切换、登录入口选择、注册信息填写、验证码解析与提交。

- XPath定位策略
  - 采用 presence+visibility 双重验证，点击前进行就绪检查。
  - 关键节点链路：语言菜单→英文选项→Creative Studio→More Tools→Sign In→邮箱登录→免费注册→邮箱/密码/确认→下一步。
  - 所有 XPath 配置位于 `kling_xpaths.json`，可根据页面版本调整。

- 兼容性与驱动
  - 依赖比特浏览器本地服务与对应版本的 chromedriver。
  - 页面就绪检测使用 `document.readyState` 与显式等待组合，适配弱网与动态渲染场景。

- 错误处理与日志
  - 捕获浏览器控制台日志与 Network 请求/响应头，用于定位前端脚本错误与网络异常。
  - 注册步骤中的安全点击与输入支持重试与回退（滚动/JS点击），并输出详细日志。
  - 在提交环节记录响应体长度，便于对比与诊断。

- 常见问题与解决
  - 打开后不执行注册：提高 Timeout/Poll；校验 XPath 是否与当前页面匹配；检查控制台与网络日志是否有错误。
  - 多窗口问题：设置并发=1时每轮仅提交1个任务；仅创建一次 CDP 新标签；默认不保留失败窗口。
  - 关闭弹窗按钮找不到：检查 `close_popup_svg` 是否与页面版本一致；查看窗口状态诊断输出。

- 故障排查指南
  - 查看运行日志中的“页面就绪”“点击步骤”“控制台日志”“HTTP请求/响应”等关键点。
  - 使用 `kling_xpaths.json` 校验关键元素是否存在与可见。
  - 如需保留失败现场以人工观察，可在注册函数调用时启用早期失败保留与最小保持时间。

## 常见问题 (FAQ)

### Q1: 启动时提示 "AttributeError" 或配置加载失败？
- **原因**: 可能是旧版本的配置文件不兼容。
- **解决**: 
  1. 删除目录下的 `gui_config.json` 文件。
  2. 重启程序，系统会自动生成新的默认配置。

### Q2: 点击"开始注册"没有反应？
- **检查**:
  1. 确认比特浏览器是否已启动，且API接口（默认54345端口）已开启。
  2. 确认"IP池"和"邮箱池"中是否有可用资源（未使用的IP和邮箱）。
  3. 检查"本次注册数量"是否大于0。

### Q3: 注册窗口无法置顶或找不到？
- **说明**: 为避免干扰操作，最新版本已取消强制置顶。
- **解决**: 注册窗口会以常规方式打开，您可以在任务栏找到它。程序会自动保持浏览器窗口的活跃状态。

### Q4: 跨平台路径问题？
- **说明**: 程序内部已处理路径分隔符（`/` vs `\`），支持相对路径。
- **建议**: 尽量将 `ip_pool.json`, `email_pool.json` 等文件放在程序同级目录下，程序会自动识别。
